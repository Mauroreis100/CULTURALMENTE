# REGRAS DE COMMITS
A rastreabilidade significa saber porquê algo mudou. Usa este padrão de mensagens:
    
    Add: Quando inseres uma nova secção (ex: Add: Introdução e Metodologia).
    
    Fix: Quando corriges um erro ou sugestão do docente (ex: Fix: Ajuste na citação bibliográfica).
    
    Refine: Quando apenas melhoras a escrita de algo já existente.
